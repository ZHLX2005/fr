# A07 · 嵌套托盘与实心分段

> 何时读：远程输入 / Smart Home 感工具页——模式切换要「实心主色滑块」而不是灰底白选 Cupertino；快捷键等控件要嵌在凹陷托盘里。
>
> 原型：`docs/prototypes/remotetype-input.html`（`.tray` / `.seg` / `.mode`）。落地参考：`lib/core/remotetype/rt_page.dart`、`rt_shortcut_bar.dart`（模块本体已迁 `lib/core/remotetype/`，布局模板在 `template/` 子文件夹）。

## 一、实现思路

### 嵌套托盘（recessed group）

```dart
Container(
  padding: const EdgeInsets.fromLTRB(10, 10, 10, 12),
  decoration: BoxDecoration(
    color: Theme.of(context).colorScheme.surfaceContainerHighest,
    borderRadius: BorderRadius.circular(16),
  ),
  child: Column(
    children: [
      // 标题行：弱字号 label + 右侧 ghost（primaryContainer 小 pill）
      // Wrap：小 chip，默认 surface 浮起；按下/busy → primary 实心 + onPrimary
    ],
  ),
);
```

- Chip 圆角 **10**，字号 **12**，padding `6×10`——**小**，不要做成大按钮。
- Ghost（历史 / 编排）：无 emoji、无 icon 亦可；`primaryContainer` + `onPrimaryContainer`。

### 实心滑动分段（发送 / 换行）

轨道 = tray 色；指示器 = `primary` 实心圆角 **11**；选中字 = `onPrimary`，未选 = `textMuted`。

```dart
Container(
  padding: const EdgeInsets.all(3),
  decoration: BoxDecoration(
    color: cs.surfaceContainerHighest,
    borderRadius: BorderRadius.circular(14),
  ),
  child: LayoutBuilder(
    builder: (_, constraints) {
      final half = constraints.maxWidth / 2;
      return Stack(
        children: [
          AnimatedPositioned(
            duration: const Duration(milliseconds: 340),
            curve: Curves.easeOutBack, // 对齐 --ease-spring
            left: isFirst ? 0 : half,
            width: half,
            top: 0,
            bottom: 0,
            child: DecoratedBox(
              decoration: BoxDecoration(
                color: cs.primary,
                borderRadius: BorderRadius.circular(11),
                boxShadow: [
                  BoxShadow(
                    color: cs.primary.withValues(alpha: 0.22),
                    blurRadius: 12,
                    offset: const Offset(0, 4),
                  ),
                ],
              ),
            ),
          ),
          Row(children: [/* 两段 InkWell 文案 */]),
        ],
      );
    },
  ),
);
```

### 配套输入区（同页时常一起出现）

| 部件 | 规格 |
| --- | --- |
| Composer | 高约 **148**，卡圆角 **18**，无 Outline 边框，靠阴影 |
| 清空 | **在输入框下方**，弱 surface pill，不是与 mic 并排 |
| Mic | 底栏**居中**唯一主操作，见 [[Ea10-胶囊与方圆角CTA]] |
| 状态 | 不要顶栏「已连接」长 pill；同步用卡内「已同步」轻闪 |

## 二、踩坑总结

| 坑 | 后果 | 正确做法 |
| --- | --- | --- |
| 用 `SegmentedButton` + 旁注说明挤一行 | 大字体/手势条裁切，最右段点不到 | 全宽自定义 Stack 分段 |
| Chip 用 A01 描边又加大 | 托盘内过重 | 托盘内用实心/浅浮起小 chip |
| 清空 + 语音并排底部 | 违背原型「mic 独主」 | 清空贴 composer 下；mic 居中 |
| 快捷键条无托盘直接贴白底 | 缺 Smart Home「嵌套」感 | 必须 `surfaceContainerHighest` 井 |
