## 全局红线

- `lib/` 新增 UI 禁止裸写 `Color(0xFF...)`；使用 Theme/ColorScheme 或项目颜色 strategy。
- 先判断功能型/内容型，再选样式或颜色策略；不要把组件配方与主题 token 架构混为一谈。
- FR 具体主题与策略以当前代码为准。旧文档中的版本、数量若与实现不同，按真实代码校准。
