# Eb01 — FR 主题架构路由

> Eb 是 E 大序列中的主题/颜色架构子序列。本文件维护 Eb02–Eb05 全部成员路由；总入口为 [[E00-UI与色彩路由]]。颜色在哪里使用、页面如何选色属于 Ea。

FR 当前主题系统是 tokens、theme、strategy、ThemeExtension 和消费 API 组成的色彩架构。具体主题名、角色、通道数量和实现路径必须以当前代码核对；文档旧版本数字可能滞后。

## Eb 序列成员

| 文档 | 何时读取 |
|---|---|
| [[Eb02-系统架构与数据流]] | 刚接触主题系统，了解分层、文件职责和切换时的数据流 |
| [[Eb03-扩展SOP与迁移]] | 新增主题、强调色角色、组件主题样式，或迁移硬编码颜色时 |
| [[Eb04-颜色用量审计]] | 评审目录用色规模、迁移完整度、残留 hex 和热点文件时 |
| [[Eb05-颜色特例策略]] | 处理 Tetris/teamAvatar 等固定识别色、需要不随主题变化时 |

## 颜色策略红线

- `lib/` 新增 UI 默认禁止裸写 `Color(0xFF...)`；先消费 ColorScheme 或项目 strategy。
- 只有业务语义要求颜色稳定、切主题会造成身份/规则误读时，才考虑固定识别色特例；按 Eb05 审核。
- Strategy/ThemeExtension 的创建和迁移遵循 Eb03，不在组件或页面内临时建立第二套主题机制。
