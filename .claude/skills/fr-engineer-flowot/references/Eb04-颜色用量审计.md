### `context.torchProtect`（4 个 UI 环境角色，scheme 派生）—— ⚠️ 无 context 入口
strategy 只承载 4 个护眼 UI 角色（protectWarmYellow/Orange/Neutral/CoolWhite，从 scheme 派生），
`TorchProtectColorStrategyExtension` 已在 `lib/core/theme/app_theme.dart:156` 注册进 ThemeData。

**但 `lib/core/theme/context/` 下没有 torch 扩展文件**（只有 board_colors / chess_colors / colors /
sudoku_colors / team_avatar_colors / tetris_colors 六个），`grep -rn "get torchProtect" lib/` **0 命中**
→ `context.torchProtect` 现在**不可用**。要读护眼策略只能自己写
`Theme.of(context).extension<TorchProtectColorStrategyExtension>()`，或先补一个 context 扩展。

10 种补光预设**不走本通道**：`lib/design_tokens/color/torch.dart` 的 `TorchColors.presets` 是
补光实际输出色（主题豁免 const 表），2026-10 起由 `torch_demo.dart` **直连消费（单一来源设计）**，
不再视为越层。

## 6. 目录推荐配色策略速查

| 目录类型 | 推荐通道 | 理由 |
| --- | --- | --- |
| 业务壳层（profile/chat/setting） | `Theme.of(context).colorScheme.X` + `context.colors` | 跨主题一致性高 |
| 棋盘/棋类游戏（gomoku/reversi/jungle） | `context.boardColors` | 棋子黑白关系 + 棋盘环境独立 |
| **国际象棋** | **`context.chessColors`** | **两色格 + 选中/将军/升变（v6.2.1 新通道）** |
| 俄罗斯方块 | `context.tetrisColors` | 7 方块识别色锁定，玩家靠颜色识别 |
| 团队卡头像 | `context.teamAvatar` | 6 头像色锁定，色 = 身份 |
