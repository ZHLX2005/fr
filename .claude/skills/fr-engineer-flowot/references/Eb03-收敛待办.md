# Eb03 — 收敛待办（SOP + 活清单）

> 骨架层 · 活清单。索引见 [[E00-UI骨架地图]]；判定规则见《Eb02 分层契约与放置》；组件清单见《Eb01 组件能力目录》。

>
> **何时读**：做组件层收敛排期、或执行一个收敛批次时。

## 1. 收敛工作流（一个批次怎么跑）

1. **现场测量**：跑 §4 命令组重测基线——历史快照数字（引用率、重复数）会过期，**动手前必须重测**；全量审计证据见 `docs/architecture/component-reuse-audit.md`（2026-10-23 基线）。
2. **选目标**：按 §2 热点优先级决策表排序，一个批次只吃一个热点（或一个待新建件），不混多目标。
3. **执行**：新建件按《Eb02 分层契约与放置》§3 新建组件契约（命名 / 参数化 / 落点 / 健康度）；收编存量按 §2 复用判定顺序，**禁止跳步**。
4. **验证**：改动范围 `flutter analyze`；复测 §4 引用计数命令——新件有真实调用点、旧重复样板计数下降，不新增零引用件。
5. **回写本页**：阶段表状态、待新建表增删同步更新；落地轮次史写进 `docs/architecture/ui-convergence-history-2026-10.md`，不留在册内。

## 2. 热点优先级决策表

| 优先级 | 热点类型 | 特征（怎么认出来） | 动作 |
|---|---|---|---|
| **A 最高 ROI** | 已有组件的漏用 | 手写 `AlertDialog` / 裸 `SnackBar` / 裸 `IconButton` / 手写空态，而 §4 命令显示共享件消费数 ≈ 0 | 按《Eb01 组件能力目录》§1 换用现成件；**不需要新设计，先做这层**——不做这步，新建组件同样无人使用（`BaseButton` 长期零引用是前车之鉴） |
| **B 按 bug 处理** | 视觉分叉 | 同一视觉元素两套实现、两种样式（如曾有的 `GameReady*` demo/core 分叉：皮肤色 vs `colorScheme`、字号字距不同、不随主题切换） | 统一到 core 共享件；确需皮肤色变体则给共享件加显式变体，不留第二套 |
| **C 工作量最大** | 联机层未收敛 | 对局页骨架重复（lua demo 间方法逐字符相同）、共享脚本段建成但 demo 零接入、平行令牌系统未并轨 | 按 §3 阶段表 S3 推进；新代码强制用壳，存量按收益分批 |

判定歧义时：一处重复先问「有没有现成件」（→ 热点 A），再问「是不是同一个元素两种长相」（→ 热点 B），最后才考虑「要不要新建抽象」（→ 热点 C / §3 待新建表）。

## 4. 重跑命令

```bash
# 共享层采用率（基线 62 / 24 两个数字的来源）
grep -rlE "core/ui/global|core/ui/game|core/ui/ai_chat|core/ui/lab" lib --include="*.dart" | wc -l
grep -rlE "core/ui/global|core/ui/game|core/ui/ai_chat|core/ui/lab" lib/core lib/screens --include="*.dart" | wc -l

# 单组件引用数（替换组件名；0 = 死代码候选）
grep -rl "core/ui/global/button/main.dart" lib --include="*.dart" | wc -l

# 重复样板
grep -rn "showDialog\|AlertDialog(" lib/core --include="*.dart" | wc -l
grep -rn "ScaffoldMessenger.of(context).showSnackBar" lib --include="*.dart" | wc -l
grep -rn "IconButton(" lib/core lib/screens --include="*.dart" | wc -l
grep -rn "CircularProgressIndicator" lib/core --include="*.dart" | wc -l

# 主题化
grep -rn "Color(0x" lib --include="*.dart" | wc -l
grep -rn "withOpacity" lib --include="*.dart" | wc -l
grep -rln "context.colors" lib/core --include="*.dart" | wc -l

# GameReady 五件套采纳率（排除定义文件）
grep -rn "GameReadyRoomCodeChip\|GameReadyAvatar\|GameReadyStatusBadge\|GameReadyCtaStyle\|GameReadyTitleRule" lib --include="*.dart" | grep -v game_ready_style.dart

# 脚本层聊天/表情接入（0 = 未接共享段）
for f in $(find lib -name "*script*.dart"); do echo "$(grep -c 'CHAT\|EMOJI' $f)  $f"; done

# 对局页骨架
for f in lib/lab/demos/*_lua/widgets.dart; do echo "--- $f"; grep -nE "^  Widget _build|^class _" "$f"; done

# 超大文件
find lib -name "*.dart" -exec wc -l {} + | sort -rn | head -30
```
