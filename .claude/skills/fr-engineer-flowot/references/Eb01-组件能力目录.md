## 2. 目录规范（2026-10-28 用户裁决，硬约束）

```text
lib/core/ui/global/<类别>/main.dart      # 全局件：被 ≥2 个域消费才允许放这里
lib/core/ui/<域>/<类别>/main.dart        # 专类件：只服务一个域时归该域
lib/core/ui/lab/<demo>/<类别>/main.dart  # lab demo 域
lib/core/utils/<类别>/main.dart          # 工具函数（镜像同粒度）
```

- **main.dart 是类别唯一入口**；类别总行数 ≤ ~400 行时 main.dart 直接装全部代码，超出时 main.dart 做 barrel、实现文件同目录并列（私有 `_` 前缀文件不 export）。
- `ui/global_ring/`（特性级悬浮环）与非组件文件不受类别规范约束，原位保留。
- 判定口径：只看**消费域集合**。≥2 域 → global；单域 → 该域。

## 4. 放组件三问

```text
① 会被 ≥2 个业务域消费吗？
   ├─ 否 → 留在本域：lib/core/ui/<域>/<类别>/main.dart
   └─ 是 → lib/core/ui/global/<类别>/main.dart
② 类别归谁：按形态归（button/nav/dialog/dot/section/empty_state/notification/renderers/zen/chat/…）；
   新形态才建新类别目录，且一个类别只做一种职责。
③ 只是本模块私有的小部件？
   └─ 留在业务模块内（私有 _ 前缀）——这是正确做法，不要下沉。
```

依赖方向硬约束：`global/<cat> → theme/token`；`ui/<域>/<cat> → global/* + game_kit(逻辑) + net_engine`；业务模块 → 以上全部。**逻辑层（game_kit/net_engine/net_p2p/message_net/theme/storage）不得 import `core/ui/`**。
