# Ea11 — 大厅与房间就绪

> 何时读：象棋（及共享 GameLobby）入口页、房间等待/就绪、匹配中转场；要对齐 `feature-list-and-lobby.html` / `game-surfaces-palettes.html` 的 lobby · room 块。
>
> 代码锚点：`kChessLobbySpec`、房间就绪共享实现 `lib/core/ui/game/game_ready_style.dart`。

## 一、已有共享实现（先查这里）

房间就绪卡**已有完整共享实现**，不要手写等价物：

| 元素 | 共享类 | 位置 |
| --- | --- | --- |
| 外卡（无边框、双层软阴影） | `GameReadyFloatCard` | `game_ready_style.dart:12` |
| 房间码胶囊 | `GameReadyRoomCodeChip` | `:58` |
| 标题下短分割条 | `GameReadyTitleRule` | `:87` |
| 座位头像（圆环 + 勾/首字） | `GameReadyAvatar` | `:105` |
| 就绪徽章 | `GameReadyStatusBadge` | `:150` |
| 就绪 CTA 样式 | `GameReadyCtaStyle.filled / .outlined` | `:182` |

**当前采纳率**：4 个 core 房间页（`chess` / `xiangqi` / `draughts` / `sudoku` 的 `*_room_page.dart`）全部使用；**7 个 lua demo（`lib/lab/demos/*_lua/widgets.dart`）只用了 `GameReadyFloatCard.decoration()` 一个静态方法，其余五件全部手写等价物**。

> ⚠️ **视觉分叉（已核实）**：demo 侧手写的房间码胶囊走 `theme.btnText`（BoardTheme 皮肤色）+ 边框 + 字号 24 / 字距 8；core 侧 `GameReadyRoomCodeChip` 走 `colorScheme.primaryContainer` / `onPrimaryContainer` + 无边框 + 字号 22 / 字距 6。**同一个房间号在应用内呈现两种视觉，且 demo 版不随全局主题切换。** 统一方式：demo 改用 core 共享件（推荐），或给 `GameReady*` 增加 `BoardThemeData` 变体。

## 二、大厅入口栈（上→下单一重心）

1. **Mark**：约 88×88，圆角 ~28，`primaryContainer` 或主题纹样
2. **标题 + 一句副文**
3. **表单卡**：圆角 **22–24**，浮在暖底（[[Ea08-Zen浮卡少描边]]）
4. **主 CTA**：全胶囊（`StadiumBorder`，高度 56），色走 **`primary`** —— `lib/core/ui/game/_lobby_form.dart:245-251` 明确「禁止 tertiary 反色抢戏」
5. **弱 hint** 一行，居中 `textMuted`

不要在第一屏再塞规则长文、统计条、第二主按钮。

### 房间就绪卡（当前实现规格）

| 元素 | 规格 | 真值来源 |
| --- | --- | --- |
| 外卡 | 圆角 22，surface 浮起，双层软阴影，无描边 | `GameReadyFloatCard`（`game_ready_style.dart:12-56`） |
| 房间码 | `primaryContainer` 底 + `onPrimaryContainer` 字，字号 22 / 字距 6 | `GameReadyRoomCodeChip`（`:58-83`） |
| 座位行 | 头像 + 名 + 就绪徽章；**就绪 = 描边强调**，非整行填色 | `GameReadyAvatar`（`:105`）+ `GameReadyStatusBadge`（`:150`） |
| 动作 | **全胶囊** `StadiumBorder`，高度 50，`primary` 填充或 `primary@0.45` 描边 | `GameReadyCtaStyle`（`:182-210`） |

> ⚠️ **历史文档更正**：本文件此前写「动作：方圆角 **12** 的 stacked Filled/Outlined——此处不用全胶囊抢大厅仪式」。**与代码不符**——现为全胶囊。以代码为真值；「房内改回方圆角」是**未落地的设计建议**，不是现状。

## 五、踩坑总结

| 坑 | 后果 | 正确做法 |
| --- | --- | --- |
| 大厅第一屏多 CTA + 规则墙 | 无视觉重心（原型 brief 点名） | 只留一个胶囊主按钮 |
| 就绪座位整行 primary 填充 | 过重、难扫谁未就绪 | 就绪 = 细描边 / chip |
| 房内 CTA 与大厅 CTA 都用胶囊 | 两者撞车 | **当前实现确实是全胶囊**；若要差异化，需同时改 `game_ready_style.dart` 与 `_lobby_form.dart`，不能只改一边 |
| 手写「就绪卡 / 房间码胶囊 / 就绪徽章」 | 与 `GameReady*` 形成第二套样式，且 demo/core 不同色 | 用 `GameReady*`（本文件第一节） |
| demo 侧用 BoardTheme 皮肤色做就绪卡 | 不随全局主题切换 | 走 `colorScheme`；确需皮肤色则给共享件加显式变体 |
| 笔刷洗色 ≠ 下一页底色 | 闪白/闪绿 | wash = `Theme.scaffoldBackgroundColor`（转场已下线，暂无实际风险） |
