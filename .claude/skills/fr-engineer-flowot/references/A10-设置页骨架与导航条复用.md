# A10 — 设置页骨架与导航条复用

> **何时读**：新建/改造一个模块的设置页；给页面选页头导航（title 版 / 无 title 版 / 浮层行 / 浮卡胶囊）；发现手写页面骨架想收编时。
> 组件资产清单与判定规则（何时抽、放哪层）归 E 序列：《Eb01 组件能力目录》《Eb02 分层契约与放置》；本页只管「开发时怎么选、怎么用」。

## §1 模块设置页：一律用 SettingsPageScaffold 家族

### 决策

| 页面形态 | 做法 |
|---|---|
| 模块设置页（列表/分区/卡片形态） | **必须**用 `core/ui/global/settings/` 四件套，不自写 Scaffold+AppBar+卡片 |
| 预览调参/选择器形态（如棋盘皮肤选择器、音游调速台） | 不套骨架——它们不是设置列表页，另起设计 |
| App 自身设置（`lib/screens/settings/`） | 不消费本骨架（骨架配方源自它，它保持原样） |
| 域内分块容器（如 mnws 的 `MnWsBlock`） | 只归该域非设置页面使用；设置页一律换骨架 |

### 四件套与用法

| 组件 | 用途 | 要点 |
|---|---|---|
| `SettingsPageScaffold` | 页面壳 | 灰底画布 + `AppNavBar.standard` + ListView；`children`（常规，壳管滚动、底部留 24）与 `body`（自管滚动的页面，如 loading 分支/复用既有 builder）**二选一** |
| `SettingsSectionHeader` | 分区标题 | 卡外，直接排进 children |
| `SettingsCard` | 偏好白卡 | ListTile 行直接放（自带内边距）；表单/滑杆等裸内容传 `padding`（常用 `fromLTRB(16, 12, 16, 12)`） |
| `SettingsCardSeparator` | 卡内行分隔 | 只缩进 16 的细线，插在行与行之间 |

最小样板（children 模式）：

```dart
return SettingsPageScaffold(
  title: 'XX 设置',
  actions: [/* 保存按钮等顶部动作，可省 */],
  children: [
    const SettingsSectionHeader('分组'),
    SettingsCard(
      children: [
        ListTile(title: const Text('项'), onTap: ...),
        const SettingsCardSeparator(),
        ListTile(title: const Text('项'), ...),
      ],
    ),
  ],
);
```

收编存量设置页的步骤：① 壳替换（Scaffold+AppBar → 骨架；表单页/loading 态走 body 模式）；② 裸分区标题 → `SettingsSectionHeader`；③ 裸字段/控件分组进 `SettingsCard(padding)`；④ 页面级色块横幅（`primaryContainer` 之类）删除，改分区标题；⑤ 顺手清不再用的域内块容器 import 与底栏 reserve（push 页不显示底栏）。

## §2 页头导航：AppNavBar 四变体决策表

| 变体 | 形态 | 何时用 | 典型页 |
|---|---|---|---|
| `AppNavBar.standard` | AppBar 规范（返回 + 左对齐标题 + actions） | **title 版**：有标题的子页/设置页默认 | 各模块设置页、rt 设置页 |
| `AppNavBar.compact` | 无 title 紧凑行：小玻璃返回钮 + 内容插槽 + 顶部小玻璃操作钮 | **无 title 版**：让内容占满、头部只留小按钮的板块 | rt 操作页共享头部、课程表 |
| `AppNavBar.floating` | 全出血内容上的浮层行 | 浮在画布/渐变上的头部（`backStyle: solid/plain`） | line 三页、focus 计时头部 |
| `AppNavBar.pill` | 浮卡胶囊条（圆角卡） | 卡片式页头 | 阅读器顶栏 |

**返回契约差异（选型后第一件核对的事）**：

- `standard`：AppBar 自带 `automaticallyImplyLeading`，不用管。
- `floating` / `pill`：传 `onBack` 即显示返回钮，组件内部带 `navCanPop` 闸门（钉选根页自动隐藏）。
- `compact`：**无闸门**——显示与否完全由调用方传不传 `onBack` 决定。适合「返回 = 页内状态切换」的钉选根页（rt 详情→大厅）；Navigator.pop 型页面调用方自己按 `navCanPop(context)` 条件传。

compact 顶部操作钮与返回钮同规格：`BaseIconButton(variant: glass, size: kCompactNavControlSize, iconSize: kCompactNavControlIconSize)`（32/18，规格档随组件导出，别自己写数字）。

一行样板：

```dart
appBar: const AppNavBar.standard(title: 'XX 设置');          // title 版
AppNavBar.compact(onBack: navCanPop(context) ? () => Navigator.maybePop(context) : null,
                  actions: [/* glass 小钮 */]);               // 无 title 版
```

**禁止再造手写 nav**：特殊视觉通过变体参数/插槽表达，豁免色在调用点显式传参（组件不写死）。底栏（`QuickNavBottomBar`）容量档位与外壳宽度自适应见 [[A09-设置容器与导航目录注册]] 与《Ed03 胶囊浮动底部导航》。
