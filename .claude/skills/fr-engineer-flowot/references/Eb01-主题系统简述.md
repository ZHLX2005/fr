# Eb01 — 主题系统简述

> Eb 是 E 大序列中的主题/颜色架构子序列。本文件 = 旧「Eb01 路由」+「Eb02 架构与数据流」合并（2026-10-24），是 Eb 子序列的**唯一入口**：先在这里看懂系统，再按需下钻。颜色在哪里使用、页面如何选色属于 Ea；token 数值字典见 [[Eb06-token变量定义]]。
>
> 具体主题名、角色、通道数量和实现路径必须以当前代码核对；本文数字滞后时以代码为准。

## 一、7 套主题

`AppThemeMode`（`lib/core/theme/colors/theme_mode.dart:7`）：

| mode | 名称 | 明暗 | 色向 |
|---|---|---|---|
| `purple` | 暮紫 | 深 | 暮紫主色 + 冷炭紫环境 + 稀用鎏金 |
| `zen` | 茶禅 | 浅 | sage 绿 + 暖米环境 + 陶土红强调 |
| `ink` | 墨白 | 浅 | 墨黑主色 + 暖生宣纸底 + 章印朱红 |
| `rose` | 粉雾 | 浅 | 近白页 + 尘玫瑰 CTA |
| `lemon` | 柠檬鼠尾草 | 浅 | 黄油主色 + 低彩鼠尾草 |
| `cobalt` | 宝蓝 | 浅 | 宝蓝 + 纯白高对比 |
| `dark` | 暗黑 | 深 | 暗底高对比 |

对应色板文件：`lib/design_tokens/color/palettes/{purple,zen,ink,rose,lemon,cobalt,dark}.dart`（一套 mode 一个文件）。

## 二、分层链路（设计主线）

```text
design tokens / palettes            ← lib/design_tokens/（Layer 1，纯常量）
    → Theme / ColorScheme           ← lib/core/theme/app_theme.dart 装配
    → domain ColorStrategy          ← lib/core/theme/colors/strategy/（每域一个契约 + default 实现）
    → ThemeStrategyFactory + ThemeExtension ← factory.dart + lib/core/theme/extensions/
    → ThemeData 注入 MaterialApp
    → context.colors / boardColors / chessColors / sudokuColors / teamAvatar / tetrisColors
```

依赖方向自上而下：token 不依赖组件；组件不各自造调色板。策略缓存与默认构造走 `factory.dart` / `Default...Strategy.of(scheme)`，不绕过。

> ⚠️ `torchProtect` **不在** context 消费链路上：`TorchProtectColorStrategyExtension` 已注册（`lib/core/theme/app_theme.dart:156`）但 `lib/core/theme/context/` 无 torch 入口；要读它得自己 `Theme.of(context).extension<TorchProtectColorStrategyExtension>()`。`AppColorsExtension`（12 个语义角色）同理**暂无 context 访问器**。

## 三、取色通道速查（写 UI 时看这张表）

| 诉求 | 入口 | 角色 |
|---|---|---|
| Material 语义（primary/onSurface/error…） | `Theme.of(context).colorScheme` | M3 原生全套 |
| 应用语义角色（主文字/弱文字/描边/面底/强调/危险） | `context.colors` | `ColorStrategy` 6 角色：`accent` `surface` `outline` `text` `textMuted` `danger` |
| 成功/警告/信息（跨主题固定语义色） | **暂无 context 入口** | `AppColorsExtension` 12 角色（success/warning/info 各 on/container 4 形态），`app_theme.dart:90-92` 注入 |
| 棋盘/棋类域内色 | `context.boardColors` / `context.chessColors` / `context.sudokuColors` / `context.tetrisColors` / `context.teamAvatar` | 各域 strategy（角色数见 [[Eb06-token变量定义]] §3） |
| 固定识别色（不随主题变） | 见 [[Eb05-颜色特例策略]] | tetris 方块 7 色、team 头像 6 色等 |
| 几何/字体 token | `AppRadius` / `AppSpacing` / `AppFontFamily` / `AppFontWeight` | 见 [[Eb06-token变量定义]] §1–§2 |

## 四、主题切换数据流

```text
用户选择 AppThemeMode
   ↓ themeNotifierProvider / ThemeNotifier 更新状态
   ↓ themeDataProvider 调用 AppTheme 组装 ThemeData
   ↓ ThemeStrategyFactory 从新 ColorScheme 创建各 domain strategy
   ↓ ThemeExtension 注入 MaterialApp 的 ThemeData
   ↓ widget 读取 context.*Colors 或 Theme.of(context).colorScheme
```

## 六、红线

- `lib/` 新增 UI 默认禁止裸写 `Color(0xFF...)`；先消费 ColorScheme 或项目 strategy。
- 只有业务语义要求颜色稳定、切主题会造成身份/规则误读时，才考虑固定识别色特例；按 Eb05 审核。
- Strategy/ThemeExtension 的创建和迁移遵循 Eb03，不在组件或页面内临时建立第二套主题机制。
- `lib/core/theme/context/` 目前只有 6 个消费文件（colors / board_colors / chess_colors / sudoku_colors / team_avatar_colors / tetris_colors）；引用「`context.torchProtect`」「`context.appColors`」都是**不存在的 API**（补入口见 Ec02 待办）。
