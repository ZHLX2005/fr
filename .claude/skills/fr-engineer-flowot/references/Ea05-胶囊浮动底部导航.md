# Floating Pill Bottom Navigation

> 分类：样式大类 = **Bottom Bars**，子类 = **Floating Pill Bottom Nav（胶囊滑动指示器底部导航）**。

视觉目标：底部一条**宽度自适应**的胶囊形毛玻璃外壳（高 64、圆角 32），均分 N 个 Tab；选中项背后一枚**宽度自适应**的小胶囊（高 48、圆角 24、primary@14%）会在切换时用自定义弹跳曲线（指数衰减余弦）从上一个 Tab 滑到下一个图标下方。

**参数真值来源**：生产实现 `lib/core/ui/shell/quick_nav_bottom_bar.dart`（`QuickNavBottomBar`）。本文所有几何/时长/颜色数值均以该文件为准。

> `lib/lab/demos/bottom_bar_demo.dart` 的 `_LegacyBottomBar` 是 demo 专用旧版（几何 52/68、曲线 `Cubic(0.65,0,0.35,1)`、400ms），**没有**指数衰减曲线、**没有** k/ω 参数，与生产实现无关，不要照抄。旧配方里的 `XiaoDouZiBottomBar` 类名在当前代码库中**已不存在**——仅 `lib/core/ui/global_ring/const_global_ring.dart:25` 留了一条提到它的过期注释。

> 外壳以 `Stack` 浮层挂载，**不要**用 `Scaffold.bottomNavigationBar`——那会铺一个矩形槽位并露出 Scaffold 底色。

## 一、实现思路

### Step 1 · 状态：prev / currentIndex / AnimationController

```dart
class _QuickNavBottomBarState extends State<QuickNavBottomBar>
    with SingleTickerProviderStateMixin {
  late final AnimationController _ctrl;
  late final CurvedAnimation _curve;
  int _prev = 0;
  int _current = 0;

  @override
  void initState() {
    super.initState();
    _current = _indexOfSelection();
    _prev = _current;
    _ctrl = AnimationController(
      duration: const Duration(milliseconds: 380),
      vsync: this,
    );
    _curve = CurvedAnimation(parent: _ctrl, curve: const _IosSpringCurve());
  }

  @override
  void didUpdateWidget(covariant QuickNavBottomBar old) {
    super.didUpdateWidget(old);
    final next = _indexOfSelection();
    if (next != _current) {
      _prev = _current;          // 记录起点
      _current = next;
      _ctrl.forward(from: 0);    // 重启动画
    }
  }

  @override
  void dispose() { _curve.dispose(); _ctrl.dispose(); super.dispose(); }
}
```

生产实现（`quick_nav_bottom_bar.dart:83-103`）用 `_prev` / `_current` **两个**字段：`didUpdateWidget` 比对新的选中槽位（`_indexOfSelection()`，末位槽可能是 `⋯` 也可能是设置直连入口）与 `_current`，不同才记 `_prev` 并重启动画；`_prev` 在动画进行中保持不变。

动画时长 **380 ms**（`:88`），不是 300 ms。

### Step 2 · 弹跳曲线（指数衰减余弦）

```dart
import 'dart:math' show exp, cos;

class _IosSpringCurve extends Curve {
  const _IosSpringCurve();
  @override
  double transform(double t) => 1 - exp(-5.2 * t) * cos(7.5 * t);
}
```

- `Curves.linear` / `easeOutCubic`：胶囊机械滑动 / 减速但不弹
- `Curves.elasticOut`：弹过头（多次过冲）
- `_IosSpringCurve`：指数衰减包络 + 单次过冲 → "Q 弹"视觉
- 经验公式 `1 - exp(-k·t)·cos(ω·t)`，生产壳底栏 `QuickNavBottomBar` 取 `k=5.2 / ω=7.5`（`quick_nav_bottom_bar.dart:21`），是肉眼调好的"够弹不过头"

### Step 3 · 几何参数与 capsuleLeft

```dart
static const double barHeight = 64;    // 外壳高（不含系统 safe-area）
static const double barBottomGap = 16; // 外壳下方额外空隙
static const double _capsuleH = 48;    // 指示胶囊高

// 胶囊宽随可用宽度自适应，两端夹在 [56, 88]
final itemW = constraints.maxWidth / n;
final capsuleW = (itemW - 8).clamp(56.0, 88.0);

double leftOf(int idx) => idx * itemW + (itemW - capsuleW) / 2;
```

- **宽度是自适应的**：生产实现用 `LayoutBuilder` 取 `constraints.maxWidth` 实时算 `itemW` 与 `capsuleW`（`quick_nav_bottom_bar.dart:173-179`），没有固定的 `_barWidth = 328`。靠外层 `EdgeInsets.symmetric(horizontal: 28)`（`:151`）留出悬浮边距，而不是靠固定宽度。
- 胶囊竖直居中：`(_barHeight - _capsuleH) / 2` = `(64 - 48) / 2` = 8
- 胶囊圆角 = `_capsuleH / 2` = 24；外壳圆角 = `_barHeight / 2` = 32

### Step 4 · 外壳 + 两层 Stack（顺序关键）

```dart
SizedBox(
  height: _barH + bottomInset + QuickNavBottomBar.barBottomGap,   // 64 + inset + 16
  child: Align(
    alignment: Alignment.topCenter,
    child: Padding(
      padding: const EdgeInsets.symmetric(horizontal: 28),        // 悬浮边距
      child: ClipRRect(                                           // (1) 外壳裁圆角
        borderRadius: BorderRadius.circular(_barH / 2),
        child: BackdropFilter(
          filter: ImageFilter.blur(sigmaX: 22, sigmaY: 22),        // 毛玻璃
          child: Container(
            height: _barH,
            decoration: BoxDecoration(
              color: cs.surface.withValues(alpha: 0.78),
              borderRadius: BorderRadius.circular(_barH / 2),
              border: Border.all(color: cs.outlineVariant.withValues(alpha: 0.35)),
              boxShadow: [
                BoxShadow(
                  color: Colors.black.withValues(alpha: 0.08),
                  blurRadius: 28,
                  offset: const Offset(0, 10),
                ),
              ],
            ),
            child: LayoutBuilder(
              builder: (context, constraints) {
                final itemW = constraints.maxWidth / n;
                final capsuleW = (itemW - 8).clamp(56.0, 88.0);
                double leftOf(int idx) => idx * itemW + (itemW - capsuleW) / 2;
                return ClipRect(
                  child: Stack(children: [
                    // (2) 滑动胶囊指示器（AnimatedBuilder + Positioned）
                    AnimatedBuilder(
                      animation: _curve,
                      builder: (context, _) {
                        final t = _curve.isDismissed ? 1.0 : _curve.value;
                        final left = leftOf(_prev) + (leftOf(_current) - leftOf(_prev)) * t;
                        return Positioned(
                          left: left,
                          top: (_barH - _capsuleH) / 2,
                          child: Container(
                            width: capsuleW,
                            height: _capsuleH,
                            decoration: BoxDecoration(
                              color: cs.primary.withValues(alpha: 0.14),
                              borderRadius: BorderRadius.circular(_capsuleH / 2),
                            ),
                          ),
                        );
                      },
                    ),
                    // (3) Tab 行（Row + Expanded + GestureDetector）
                    Row(children: [
                      for (var i = 0; i < visibleEntries.length; i++)
                        Expanded(child: _NavTab(...)),
                      Expanded(child: _buildLastSlot(cs)),   // 末位槽：⋯ 或设置直连
                    ]),
                  ]),
                );
              },
            ),
          ),
        ),
      ),
    ),
  ),
);
```

**层序**：外壳（`ClipRRect` → `BackdropFilter` → 半透明 `Container`）→ `Stack` 内 (2) 指示胶囊 → (3) Tab 行。胶囊在图标之下，让图标 primary 实色浮在胶囊 primary@14% 半透明上 → 既有深度又有 identity。

生产实现用 `Container` + `BoxDecoration` 而不是 `Card`——`Card` 的 elevation 会带来 Material tint，且默认会把形状矩形化。

### Step 5 · 颜色

```dart
final primaryColor = cs.primary;
final inactiveColor = primaryColor.withValues(alpha: 0.42);   // 生产实况
```

- 选中：图标 = primary 实色，胶囊 = primary@**14%**
- 未选中：图标 = primary@**42%**（图标与文字共用同一个 alpha）
- **只用 primary 一种色**（不同 alpha 衍生），不要 onSurface 派生

### Step 6 · 验收

- [ ] 初始选中槽：胶囊停在该槽中心
- [ ] 切换：胶囊弹跳滑到新槽（旧图标回灰、新图标变 primary）
- [ ] bottomInset + `barBottomGap`(16) 防止 home indicator 遮挡
- [ ] 重复点同 Tab：didUpdateWidget 检测相等、不重启动画
- [ ] dispose 释放 _ctrl / _curve
- [ ] 主题切换：胶囊与图标颜色随 cs.primary 联动
- [ ] 窄屏（如 4 槽 + 横屏）：胶囊宽夹到下限 56 不越界，宽屏夹到上限 88

## 二、踩坑总结

> 本节为本方案实操踩过的真坑。"现象 → 根因 → 结论"格式。

### 坑 1 · `width: double.infinity` 撑满 → 失去悬浮感

撑满屏就回到 Material 默认 bottom bar 风格。**结论**：用外层 `EdgeInsets.symmetric(horizontal: 28)` 留悬浮边距 + `LayoutBuilder` 按可用宽度自适应，**不要** `double.infinity` 撑满，也不要写死固定宽度（固定宽度在窄屏/大屏都不对）。

### 坑 2 · 胶囊位置与 Tab 中心错位

`leftOf(idx) = idx * itemW + (itemW - capsuleW) / 2` 要求 `itemW` 严格等分。**结论**：生产实现就是用 `LayoutBuilder` 取 `constraints.maxWidth` 实时算 `itemW`（`quick_nav_bottom_bar.dart:173-179`）——**必须用 LayoutBuilder 动态算**，因为外壳宽度本身随屏幕宽度和 `horizontal: 28` 内边距变化，写死宽度必然在不同机型错位。胶囊宽用 `(itemW - 8).clamp(56, 88)` 夹紧，避免窄屏时胶囊比槽还宽。

### 坑 3 · Active 图标被胶囊"压在身后"

Stack 顺序写反（胶囊在图标之上）→ 选中图标完全被胶囊色块覆盖。**结论**：固定 `Card → AnimatedBuilder(capsule) → Positioned.fill(icons)`。

### 坑 4 · didUpdateWidget 里写 `setState`

不需要。`setState` 触发 widget 树重建是无意义成本，动画靠 `_ctrl.forward()` 驱动。**结论**：didUpdateWidget 只负责记录 `_prev` + 重启动画，**不要**写 `setState(() {})`。

### 坑 5 · 用 `Curves.elasticOut` 替代 QQ → 抖动过头

elasticOut 内置多次过冲，胶囊来回抖几次。**结论**：`_IosSpringCurve` 单次过冲刚好；嫌弹可换 `Curves.easeOutCubic` / `Curves.easeOutBack`；注意 elasticOut 的过冲系数可能让 t 越过 [0,1]，需手动 `t.clamp`。

### 坑 6 · primary 实色给图标 + 胶囊同时 → 视觉扁平

primary + primary 都是实色 → 单色 plane 无 depth。**结论**：胶囊 = primary@14%、图标 = primary 实色，active 视觉靠"图标实色 + 胶囊浅色"两层叠出。

### 坑 7 · 给胶囊加 elevation / shadow

`Container` 的 `borderRadius + color` 不自动裁剪，加 shadow 后会出现方角。**结论**：胶囊本身无阴影，borderRadius 直接生效；如未来给胶囊加阴影必须显式包 `ClipRRect(borderRadius: ...)`。外壳的阴影（黑 @0.08 / blur 28 / offset (0,10)）加在**外壳** `Container` 上，且外壳已被 `ClipRRect` 包住，不会漏角。

## 原型增量（`main-shell-nav.html`）

> 何时用：主壳要对齐原型的 **capacity 3/4**、**溢出「⋯」sheet**、glass dock。

| 点 | 做法 |
| --- | --- |
| Capacity | dock 均分不超过 3 或 4 个主 tab；超出进溢出 |
| 溢出 sheet | 底 inset、圆角 ~28、顶 handle；内嵌 4 列 mini 启动格 |
| Glass | 半透明 surface + 轻 blur（Flutter：`BackdropFilter` 或半透明 `Card`） |
| 与 Lab/Game | Lab = 功能浮卡（[[Ea08-Zen浮卡少描边]]）；Game = 封面（[[Ea06-商店式内容页]]） |

落地以 `lib/core/ui/shell/quick_nav_bottom_bar.dart`（`QuickNavBottomBar`，曲线参数 `k=5.2 / ω=7.5`）+ 壳层 overflow sheet 为准。`lib/lab/demos/bottom_bar_demo.dart` 的 `_LegacyBottomBar` 是 demo 专用旧版（几何 52/68、`Cubic(0.65,0,0.35,1)`、400ms），不含指数衰减曲线、不含 k/ω 参数——**不要**把它当成本文配方的来源。
