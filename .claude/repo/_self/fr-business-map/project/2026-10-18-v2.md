## 三、板块共享层与扩展指针

### 游戏中心
- **共享业务层**：`RelayV3Transport`（net_engine/relay_v3）· `services/lua` · 棋引擎 core/{gomoku,go,chess,draughts,jungle_chess,reversi,sudoku,surround_game,coup,team_card,tetris} · `core/game_audio`
- **共享组件**：`RelayConnectionBar`（WS 状态条）· `LobbyParticipants` 圆环 · 棋盘手势层 · 角色镜像翻转 · 棋盘皮肤（chess/gomoku · KV 管线）· 表情包 · `kGameCenterCatalog`（17 游戏登记，slug 字符级一致）
- **扩展**：新对战游戏 → relaylua B01/B03/B04 + A02 登记；大厅族 → C01；服务端权威 → A01；皮肤/封面/表情 → flutter-ui skins（A01-A03 + scripts/）

### 时间
- **共享业务层**：`core/focus` · `core/doubletime` · `core/timetable`（课表+追剧，主界面）· `services/metronome`（Oboe FFI）· `native/home_widget`
- **扩展**：workflow A04（TimePage）/ A08-A10（Hive）/ audio 子域（Oboe）/ flutter-platform widget 子域

### 联机应用
- **共享业务层**：`core/net_p2p` · relay_v3 · `api/remotetype` + `services/remotetype`（RT1 加密协议）
- **扩展**：netp2p 速查表（v1 LAN vs v3）；relaylua A01/A03

### 内容与生活 / 笔记与记录 / 设备与平台
- 共享：`core/novel_reader` · `core/gallerymanage` · `core/word_drag` ｜ `core/note`（note 子域三 ref）· `core/body` ｜ `native/overlay`（projection 子域）· torchProtect 色板

### 工程与调试
- 共享：`api/`（authhub OIDC / github / notion / kv）· `core/schema` · BoxDescriptor 注册制 · `demo_session_host`
- **扩展**：workflow A07（API 规范）/ A09（存储面板）

### AI 与聊天（服务层，无独立 demo）
- `screens/chat` + `core/ai_chat` + `services/message_strategy` + `api/minimax`；扩展 → flutter-biz message 子域
