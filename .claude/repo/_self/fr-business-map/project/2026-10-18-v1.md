# fr 业务板块地图（v1）

> **定位（A 序列基础文档）**：动手扩展任何模块前先看这——「有什么、在哪、归谁」。
> 序列语义：本地图 = **A 序列基础**（结构与事实）；**B 序列特定 SOP** 不在本文重复，各板块「扩展指针」直接指向 flutter-biz 对应 ref；C 专项深水区同理。
> 数据基线：2026-10-18 · 50 个注册 demo（`lab_bootstrap.dart` 61 次注册调用）· 35 个 core 模块 · kGameCenterCatalog 17 游戏。

## 一、全局骨架

```
App 主分区：Lab（demo 大厅）· 时间页 Focus · 课表 timetable · 聊天 chat · 我的 profile · 设置 settings
路由协议：  fr:// 自定义 scheme（fr://lab · fr://lab/demo/{slug} · fr://timetable）
```

### 全局共享基建（跨板块，各板块只写「用到了什么」）

| 模块 | 职责 |
| --- | --- |
| `core/schema` | fr:// URI/路由协议 + Schema 内嵌链接 |
| `core/nav` | 导航中心 |
| `core/theme` + `design_tokens/` | 六主题色彩架构（4 分层 + 6 Strategy + 6 消费通道） |
| `core/ui` | 原子组件库（按 subgroup 分类：atomic/lab/shell/zen/renderers…） |
| `core/net_engine` | **全局联机底座**：LAN（UDP+HTTP）+ Relay v3（HTTP+WS 快照） |
| `core/net_p2p` | 联机房间业务页（发现/模式切换/聊天） |
| `core/game_kit` | 游戏中心基建：lobby / emoji / skin / chat + kGameCenterCatalog |
| `core/storage` | Hive 存储（StorageManager + BoxDescriptor 注册制） |
| `api/` | 后端客户端（authhub / goframe / notion / github / minimax / pi / remotetype / token / user） |
| `services/lua` | Lua 房间脚本托管（Dart 字符串 → 上传后端） |
| `lib/native/` | Android 原生桥接（home_widget / overlay） |
| `lib/app_lifecycle/` | 生命周期 + MethodChannel 翻译层（深链入口） |
