## 1. 整体框架

项目内并存 **5 套颜色体系 + 1 个颜色工具 feature**，彼此独立、互不引用（仅 LabPanelColors 例外，从 ColorScheme 推导）：

```
① AppTheme 七主题（Material）
   AppThemeMode(枚举) → AppTheme.createXxxTheme() → ThemeData(ColorScheme)
   → ThemeProvider(ChangeNotifier + SharedPreferences 'app_theme_mode')
   → MaterialApp 全局 → 走 theme.colorScheme 的页面（唯一亮暗自适应通道）

② Zen 主题            ③ Paper 日式调色板
   ZenColors(7色静态)     PaperPalette(10色静态)
   ZenText + zenCard...   AppText(GoogleFonts) + Spacing
   → 407处/34文件          → 130处/20文件
   （硬编码浅色，不跟随①）  （硬编码浅色，不跟随①）

④ TimetableColors     ⑤ 领域语义色令牌
   莫兰迪8色环+中性组       ReversiThemeData / BoardThemeData(surround)
   （自述"与系统主题隔离"）  LabPanelColors.resolve(从ColorScheme推导,唯一例外)
                            ClockColorUtil(动态变暗工具)
                            note/core/text/color.dart

⊘ lib/core/color/（颜色工具 feature，不是主题）
   Cmyk/Rgb/ColorSwatchModel/ColorPaletteConst/ColorPalettePage/ColorRepository
```

**一句话**：只有体系①接进 Flutter 主题管线；②③④是静态调色板常量（各自硬编码、均为浅色）；⑤是领域语义令牌，实现方式各异。

## 2. L1 概念名称表

| 概念名 | 一句话定义 | 位置 | 与其他概念的关系 |
| --- | --- | --- | --- |
| **AppThemeMode** | 七主题枚举：light(默认蓝)/dark/pink/green/orange/rose/purple(黑紫) | `core/color/theme/app_theme.dart` | ThemeProvider 持有；每个非 dark 主题都是浅色变体 |
| **AppTheme** | 主题工厂：`getThemeData(mode)` 手写 7 套 ThemeData（ColorScheme.light/dark 全槽位） | 同上 | 产出 ThemeData 给 MaterialApp；"暖白奶油底+鲜艳主色"（surface=0xFFFFF8F0） |
| **ThemeProvider** | ChangeNotifier 主题状态：init/setThemeMode/setPink…，`app_theme_mode` 键 SharedPreferences 持久化 | `core/color/theme/theme_provider.dart` | `themeModeValue` 仅 dark 映射 ThemeMode.dark，其余全部 light |
| **ColorScheme（M3 语义槽）** | Material 官方语义槽位（primary/secondary/tertiary/surface/outline/error…） | Flutter 自带 | 只有体系①填充；LabPanelColors 是唯一从它推导的体系⑤成员 |
| **ZenColors** | zen 七色静态常量：`bg`(0xFFF4F1EA)/`ink`/`hair`/`secondary`/`sage`(鼠尾草绿)/`mutedRed`/`surface` | `widgets/theme/zen_theme.dart` | 全部硬编码浅色，不随 AppThemeMode 切换 |
| **ZenText** | zen 文字规格族：body/label/title/button/monoDigit(Small/Large，tabularFigures 等宽) | 同上 | 颜色引用 ZenColors.ink/secondary |
| **zenCard / zenDottedZone / zenButton** | zen 装饰函数（BoxDecoration/ButtonStyle 工厂） | 同上 | 组件级 zen 视觉语言 |
| **ZenSection / zenPageScaffold** | zen 复合组件（"不只是颜色，是一套 UI"）：带标签头的卡片容器/页面脚手架 | 同上 | timetable 设置页/时钟/recorder 等复用 |
| **PaperPalette** | 日式极简 10 色静态常量：`bg`(哑光奶白)/`bgElevated`/`ink`(墨黑)/`inkMuted`(淡墨)/`inkFaint`(雾墨)/`line`/`today`(朱砂红)/`accent`(茶色)/`highlight`(黄土) | `core/theme/paper_palette.dart` | 文件头自述"所有颜色走这里，禁用 Material 默认蓝" |
| **AppText** | Paper 配套字体：display/title=Cormorant Garamond（衬线），body/caption=Inter | `core/theme/typography.dart` | 默认色取 PaperPalette.ink/inkMuted |
| **Spacing** | 4/8/12/16/24 间距常量（xs~xl） | `core/theme/spacing.dart` | core/theme 三件套之一（palette/typography/spacing） |
| **TimetableColors** | 课表专属配色：`courseColors` 莫兰迪 8 色环（灰蓝/灰紫/灰粉/灰橘/灰绿/灰青/雾蓝/灰棕）+ accent/border/textPrimary…/surface 组 | `core/timetable/presentation/timetable_colors.dart` | 自述"与系统主题色隔离"；`getCourseColor(seed)` 按课程 id 取环色 |
| **ReversiThemeData** | 翻转棋语义色令牌集合，视觉栈分层命名（boardSurface/cellBase/cellFaceLight/cellFaceShadow/cellEdge + pieceBlack/White/Highlight/Rim + legalHint/lastMoveRing + panel 系） | `core/reversi/board_theme.dart` | 与 surround 的 BoardThemeData "共用同一设计语言"（注释声明） |
| **BoardThemeData** | 围绕棋（surround_game）棋盘语义令牌，同款分层命名法 | `core/surround_game/board_theme.dart` | ⑤中成对出现的领域令牌样板 |
| **LabPanelColors** | 下拉面板配色，`resolve(ColorScheme, brightness)` 从主题色阶推导渐变/accent/玻璃拟态色，亮暗自适应 | `screens/profile/lab/lab_panel/lab_panel_colors.dart` | 全项目唯一"从 ColorScheme 推导"的派生色样板 |
| **ClockColorUtil** | 时钟动态色工具：超时按比例向黑渐变（getClockColor/getBackgroundColor，缓动曲线可调） | `lab/demos/clock/utils/clock_color_util.dart` | 消费任意 baseColor，不绑定具体体系 |
| **Cmyk / Rgb / ColorSwatchModel / ColorPairModel** | 颜色工具 feature 的数据模型（印刷色/色卡对） | `core/color/color_models.dart` | 服务 ColorPalettePage，与主题系统无关 |
| **ColorPaletteConst** | 固定色卡库（炭黑/甜酷粉/深海蓝/柔奶白/茶花红…带 CMYK+RGB+HEX） | `core/color/const_color_palette.dart` | 同上，feature 数据 |
| **ColorUtils** | 颜色计算工具（mix 等），被 LabPanelColors 等消费 | `core/color/color_utils.dart` | ⑤派生色的计算底座 |
