# 项目颜色/主题概念盘点

> **Date:** 2026-08-16
> **Topic:** color-theme-concepts
> **类型:** project 现状文档（只记录现象与问题，不含设计建议）
> **版本:** v1

## 一、结论速览

项目实际存在 **4 套互不隶属的视觉体系** + 大量散落硬编码色：

1. **Material 全局主题**（`AppTheme`，7 种模式，手写 ColorScheme + 全局降饱和）
2. **Zen 暖米静态系统**（`ZenColors`，独立常量，不跟随主题）
3. **PaperPalette 日式极简**（日历系，完全隔离）
4. **棋盘/游戏语义令牌**（`BoardTheme`/`ReversiTheme` ThemeExtension + 各游戏硬编码）

硬编码统计：**172 个 lib/ 下的 .dart 文件**直接使用 `Colors.xxx` 或 `Color(0x...)`。

## 二、全局主题系统（Material 层）

### AppTheme + AppThemeMode（`lib/core/color/theme/app_theme.dart`）

- 全局唯一 Material 3 主题工厂，`MaterialApp.theme` 来源
- **7 种主题模式**（即用户可选的"主题色集合"）：

| 模式 | 显示名 | primary | 亮度 |
|---|---|---|---|
| light | 默认主题 | `#2196F3` 蓝 | 亮 |
| dark | 夜间模式 | `#7986CB` 蓝紫 | 暗 |
| pink | 粉红主题 | `#FF6B95` | 亮 |
| green | 青绿主题 | `#10B981` | 亮 |
| orange | 橙黄主题 | `#FF9500` | 亮 |
| rose | 玫瑰红 | `#E53935` | 亮 |
| purple | 黑紫主题 | `#9B8FBF` | 暗 |

- ColorScheme **全部手写** `ColorScheme.light()/dark()` + 手写 hex；**无** `ColorScheme.fromSeed`、无 seed、无 palette 生成
- 每个模式一个 `createXxxTheme()`（约 110 行/个），同时自定义 cardTheme/appBarTheme/floatingActionButtonTheme/elevatedButtonTheme/filledButtonTheme/bottomNavigationBarTheme
- **全局降饱和**：`kSaturationFactor = 0.85`，`getThemeData()` 产原始主题后 `_desaturateTheme()` 统一降饱和（不动 surface/background/onSurface/outline 中性色；暖白奶油底 `#FFF8F0` 除外）
- 私有 ThemeExtension：`_PinkThemeColors` 等 5 个，仅存 gradientStart/gradientEnd 两字段，外部不可读
- 暖白奶油底是 light/orange 的 surface（`#FFF8F0` 系）——即"主题色区域比较亮"的感官来源

### ThemeProvider（`lib/core/color/theme/theme_provider.dart`）

- ChangeNotifier，SharedPreferences 持久化 key=`app_theme_mode`
- `setLight/setDark/setPink/setGreen/setOrange/setRose/setPurple`、`toggleTheme()`、`cycleTheme()`
- **使用方仅 2 处**：main.dart、theme_page.dart；`setPink/setGreen/toggleTheme/cycleTheme` 无调用方（预留 API）

### MaterialApp 配置（`lib/main.dart`）

- `theme: themeProvider.themeData` + `themeMode: themeProvider.themeModeValue`（只返回 dark/light）
- **无 `darkTheme` 属性、不跟随系统**；深色仅 dark/purple 两模式自带
- 入口：首页 →「主题设置」→ ThemePage（7 卡片网格）

### 跟随全局主题的辅助件

- `EmphasisButton`（border-emphasis 按钮，~35 文件使用）
- `LabPanelColors`（ColorScheme 推导，lab 下拉面板）
- 底部导航、banner 渐变、markdown/html 渲染器链接色

## 三、Zen 暖米静态系统（`lib/widgets/theme/zen_theme.dart`）

- **不经过 ColorScheme、不跟随 AppThemeMode 切换**，纯 static const
- ZenColors 7 色：bg `#F4F1EA` / ink `#2C2C2C` / hair `#D9D5C8` / secondary `#8A8475` / sage `#7A9A7E` / mutedRed `#A0594A` / surface `#FBF8F1`
- 组件：ZenText（6 字体）、zenCard/zenDottedZone/zenButton/zenPageScaffold、ZenSection/ZenIconButton/ZenDot/ZenEmptyState/ZenSwipeAction/ZenConfirmDialog、formatDuration/formatTime/formatRecordDate
- 配套 `zen_date_picker.dart`（showZenDatePicker 替换系统日期选择器）
- **使用模块（27 文件）**：clock 全家（8）、metronome、recorder、relation_calc、focus 首页、timetable 设置区（含 advanced/shared/zen_controls）、native_media

## 四、PaperPalette 日式极简（`lib/core/theme/paper_palette.dart`）

- 9 色：bg `#F7F4EE` / bgElevated `#FFFFCF5` / ink `#1F1B16` / inkMuted / inkFaint / line `#E6DFD0` / today `#C8553D` 朱砂 / accent `#8B6F47` 茶 / highlight `#E9B44C`
- 配套 typography（Cormorant Garamond 衬线 + Inter）、spacing
- **使用方（17 文件）**：calendar 全 UI
- **与全局主题完全隔离**；设计文档明令"禁用 Material 默认蓝"

## 五、棋盘/游戏语义令牌与功能色

### BoardTheme / BoardThemeData（`lib/core/surround_game/board_theme.dart`）

- **26 语义 token** + warm（暖米）/ cool（紫色）两套预设
- ThemeExtension 读取（`BoardTheme.of(context)`，未注入回退 warm）
- 使用方 ~13 文件：surround_game 全模块 + 5 个 Lua 棋游 + torch + net_engine
- **不读 AppTheme 的 ColorScheme**

### ReversiTheme / ReversiThemeData（`lib/core/reversi/board_theme.dart`）

- 19 语义 token + classic（暖米）/ dark（深靛蓝）两套预设
- 使用方：reversi 模块

## 六、同源双副本现象

- **TimetableColors**（Dart `Color`，莫兰迪 8 色）+ **TimetableWidgetColors**（`lib/native/home_widget/timetable_widget_colors.dart`，同色 hex 字符串）——同一莫兰迪色在 Dart 端与桌面小组件 Kotlin 侧各存一份
- 说明：小组件侧无法直接消费 Dart Color 对象，但两处无任何同步机制

## 七、硬编码分散统计

- 172 个 lib/ 下 .dart 文件直接使用 `Colors.xxx` 或 `Color(0x...)`（排除常量定义文件后仍约 150+）
- 集中区域：游戏类（surround_game/reversi/jungle_chess/lua 棋游/snake/2048/line）、lab/demos 实验页（70+ 文件）、novel_reader、services/message_strategy（6 个策略卡片配色）
- 相对收敛：clock/metronome/recorder/relation_calc/timetable 设置（zen 化）、calendar（PaperPalette）、profile 主框架（ColorScheme）
- 特例：`image_picker_widget.dart` 用 `Colors.blue` 兜底

## 八、现状问题观察（现象记录）

1. 4 套视觉体系互不隶属：AppTheme（全局）/ Zen / PaperPalette / 游戏令牌——切换 AppThemeMode 时，zen/paper/游戏模块视觉不变
2. 同一模式只有 2 个使用方；多个 setXxx API 是死代码（预留）
3. 无 `darkTheme`、不跟随系统；深色仅 dark/purple 自带
4. 手写 ColorScheme（每模式 ~110 行）vs 无 seed 生成——模式间色系一致性靠手工维护
5. 172 文件硬编码色：同一语义（如删除红、主操作绿）在多处各自写死（zen mutedRed `#A0594A` / 删除区红 `#D63B3B` / 玫瑰红 `#E53935` 并存）
6. TimetableColors 与 TimetableWidgetColors 双副本无同步
7. 全局降饱和 `kSaturationFactor=0.85` 与 zen/paper 的静态色并存，饱和度标准不一
8. design 文档（2026-07-29 focus spec）明确"各 demo 保持各自原生主题"是有意决策；styles-skill 提供"颜色三分法"作为新落地统一决策依据
