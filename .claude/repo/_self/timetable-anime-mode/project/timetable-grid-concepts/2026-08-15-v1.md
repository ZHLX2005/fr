# timetable-grid-concepts 概念阐述（2026-08-15 v1）

> **Topic:** timetable-anime-mode
> **类型:** project doc(模块概念阐述)
> **版本:** v1（首次产出；来源：fr 28 追剧模式自建后端 + slot 体系重构对话）
> **代码权威位置:** `lib/core/timetable/domain/models.dart`（字段定义）、`lib/core/timetable/service/config/anime_dsl_generator.dart`（slot 分配）

## 1. 整体框架

```
剧模型 AnimeSeriesDraft[] (SSOT)
   │ store CRUD → 自动派生
   ▼
buildAnimeDsl 生成器（纯函数）
   │ 产出 config + items + DSL 文本
   ▼
TimetableConfig（渲染全由它驱动；渲染层不感知学校/通用/追剧模式）
   ├─ 网格骨架：cycleCount × daysPerCycle × slotsPerDay
   ├─ 视口：slotsPerPage（一屏显示几行，超出纵向滚动）
   └─ 左侧指示：leftLabelMode + slotLabels / slotStartTimes + leftWidth
   ▼
课表网格（grid）
   └─ cell = (dayOfCycle 列, slotIndex 行) 交叉点，放 CourseItem
```

**一句话**：横向是 day（列），纵向是 slot（行）；一个 cycle（周期）= daysPerCycle 天；追剧模式下每部剧独占一个 slot 行，左侧标签显示该剧开始时间。

## 2. L1 概念名称表

| 概念名 | 一句话定义 | 首次提出语境 | 与其他概念的关系 |
| --- | --- | --- | --- |
| **cycle（周期）** | 课表重复的时间单位（追剧=1周） | 课表 DSL 设计 | cycleCount=周期总数；cycle×daysPerCycle=总天数 |
| **daysPerCycle** | 每周期天数（1-7）= 网格横向**列**数 | 课表 DSL 设计 | 列=day；dayOfCycle=列号(0-based) |
| **slotsPerDay** | 每天**行**数。学校模式叫"节数"（手动上限 6）；追剧模式=剧的条数（每剧独占一行，上限 64） | fr 28 高 slots 改造 | 行=slot；slotIndex=行号(0-based) |
| **maxSlotsPerDay** | slotsPerDay 硬上限，现为 64 | fr 28（原 6，追剧独占 slot 后扩容） | updateConfig clamp 用 |
| **maxManualSlotsPerDay** | 学校/通用模式**手动**调节上限 6 | fr 28 与 maxSlotsPerDay 分离时 | 高级设置滑条上限（非追剧模式） |
| **slotsPerPage** | 一屏视口显示的行数（默认 6）；行高=屏高÷它 | fr 28 高 slots 滚动改造 | slotsPerDay 超出它 → 网格纵向滚动；范围 1-16 |
| **slot** | 纵向一行的槽位（row）本体 | 课表 DSL 设计 | 追剧模式由生成器按 (weekday,time) 分桶分配 |
| **分桶 (weekday, time)** | slot 分配规则：撞同一(星期,时刻)的多部剧各占一个 slot 并加 "(1)(2)" 后缀；同 time 跨天分属不同桶不加后缀 | fr 28 避免同 cell 覆盖 | 决定 slotLabels 内容 |
| **leftLabelMode** | 左侧指示列显示模式：0=节次序号 / 1=时间段(开始+结束) / 2=自定义文字 | 左侧指示显示控制 | 追剧模式=2；学校模式常用 1 |
| **slotLabels** | leftLabelMode=2 的自定义标签列表；追剧模式标签=开始时间标识（"20:00"/"20:00 (2)"） | fr 28 从时间段模型切自定义模型 | 逐项原样显示，空项回退序号 |
| **slotStartTimes** | leftLabelMode=1 的每节开始时间 "HH:mm" 列表 | 左侧时间段模式 | 会拼 slotDurationMin 算结束时间；追剧已不使用 |
| **slotDurationMin** | 每节时长（分钟），仅 mode=1 计算结束时间用 | 左侧时间段模式 | 追剧模式不再传 |
| **leftWidth** | 左侧指示列宽度 px（默认 64） | 左侧指示显示控制 | 高级设置可调 44-110 |
| **DSL** | 课表文本格式：`config:` 段 + 课程行（`标题 @ 星期 节次 w周次 位置`） | 课表导入导出载体 | 生成器输出可回灌 parseDsl 还原 |
| **AnimeSeriesDraft（剧模型）** | 追剧模式 SSOT：title/startDateIso/weekday/time/episodes/durationMin | fr 25 剧模型化 | CRUD → store 自动派生 DSL；Hive 持久化 |
| **AnimeDraft（API 草稿）** | 适配器拉取的剧草稿，字段全部可缺省 | 追剧适配层 | 导入对话框勾选 → importAnimeSeries 追加 |
| **AnimeSourceAdapter** | 数据源适配器接口（id/label/fetchSeason(season, year)） | fr 25 适配层 | kAnimeSourceAdapters 登记表驱动来源下拉 |
| **SelfHostedAnimeAdapter** | 当前唯一来源：自建聚合后端 `http://47.110.80.47:81` | fr 28（替代 Bangumi/AniList 直连） | 契约见 anime-backend-api-spec.md |
| **AnimeSeason** | 季度枚举（冬春夏秋，与后端 WINTER/SPRING/SUMMER/FALL 对齐） | fr 28 季节选择 | 导入对话框季节下拉 + currentAnimeSeason() |
| **buildAnimeDsl（生成器）** | 剧列表→config+items+DSL 的纯函数 | fr 25 | 分桶/anchor 锚定/周期自动膨胀 |
| **weekOffset** | 剧从第几周开始 = (start − anchor周一).inDays ÷ 7 | 落位计算 | visibleInCycles 起点 |
| **visibleInCycles** | 剧在哪些周期可见 [weekOffset .. weekOffset+episodes−1] | fr 25 追剧期数 | CourseItem 字段；DSL `w1-24` 范围 |
| **anchor 周一** | 网格起始日期 = 最早合法 startDateIso 对齐周一；全空/非法回退本周一 | fr 28 Slime bug（startDateIso=null 崩溃）修复 | 即 config.startDateIso |
| **backfillStartDate（反推）** | 当前第 N 期 → 从最近播出日回推 (N−1) 周得开播日期 | 编辑对话框"当前第N期反推" | 反推完成自动回到日期编辑态 |

## 4. L2 布局内部模块指称表

### 课表网格（timetable_page.dart）

| 模块名 | 是什么 | 父子关系 |
| --- | --- | --- |
| 天数标题行（weekday header） | 顶部"第N天 + 日期"行 | page > header |
| 周期徽标 | 左上角"第N周期"胶囊 | header > 徽标 |
| grid（网格主体） | ListView.builder 纵向滚动区（行高由 slotsPerPage 决定） | page > grid |
| **cell** | 行列交叉格 (dayOfCycle, slotIndex)，可叠多个 CourseItem | grid > 行 > cell |
| **左侧指示列（_SlotLabel）** | 每行最左标签格，按 leftLabelMode 渲染 | grid 行 > 左列 |

### 排期编辑页（timetable_anime_editor_page.dart）

| 模块名 | 是什么 | 父子关系 |
| --- | --- | --- |
| 摘要条 | 顶部自动派生结果（起始/行数/周数/剧数） | page > 摘要条 |
| 排期行（_SeriesTile） | 列表卡：时间标签 + 剧名/期数/开播日 | page > list > tile |
| 时间标签 | tile 左侧 68px 的 HH:mm 徽标 | tile > 标签 |

### 导入对话框（timetable_anime_import_dialog.dart）

| 模块名 | 是什么 |
| --- | --- |
| 季节/年份选择行 | Header 下冬春夏秋 + 年份下拉（当前年±2） |
| 来源下拉 | kAnimeSourceAdapters 渲染（现仅「自建新番表」） |
| 勾选列表 | CheckboxListTile 列表 |
