# MateusNavarro77 / GreatApe77 metronome — 架构总览

> 来源仓库: `.claude/repo/metronome-MateusNavarro77/` (上游 GreatApe77/metronome,Flutter 实现 + Native C++/Oboe 音频引擎)

## 1. 项目定位

来自 `README.md:57-65`:

> A simple and effective metronome application built with Flutter. … It offers adjustable BPM, visual feedback, and clear audio cues for practice sessions. Key features include: Adjustable BPM … Play/Pause Control … Visual Beat Indicator … Accent on First Beat … Audio Cues … Theme Toggle.

技术上这是一个 **Flutter 跨平台节拍器**,但音频合成下沉到 Android NDK (C++ + Oboe)。当前在 `lib/ffi.dart:7` 只为 Android 加载 `libmetronome.so`(其他平台未实现):

```dart
// 来源: lib/ffi.dart:5-8
static final DynamicLibrary _lib =
    Platform.isAndroid
        ? DynamicLibrary.open("libmetronome.so")
        : throw UnsupportedError("Platform not supported");
```

## 2. 模块划分

| 目录 | 职责 | 关键文件 |
|------|------|----------|

| `blocs/theme/` | 主题持久化 | `theme_bloc.dart`、`theme_event.dart`、`theme_state.dart` |
| `shared/` | 常量与主题 | `constants.dart`、`app_theme.dart`、`theme_colors.dart` |
| `view/pages/` | 页面 | `home_page.dart` |
| `view/widgets/` | UI 组件 | `bpm_display.dart`、`bpm_slider.dart`、`measure_bar.dart`、`metronome_controls.dart`、`pulse_button.dart`、`tap_bpm_fab.dart`、`time_signature_picker.dart`、`time_signature_selector.dart` |

Native 端 (Android):

```

```

## 3. 入口与核心数据流

`main.dart` → `view/app_widget.dart` → `view/pages/home_page.dart` ←→ `MetronomeBloc` ←→ `MetronomeImpl` ⇄ FFI ⇄ C++ `Metronome` (Oboe)

`lib/ffi.dart:44-62` 将 7 个 C 函数封装为 Dart 静态方法:

```dart
// 来源: lib/ffi.dart:44-62
static void init(double bpm) => _initAudio(bpm);
static void play() => _play();
static void pause() => _pause();
static void shutdown() => _shutdownAudio();
static void setBpm(double bpm) => _setBpm(bpm);
static void setBeatsPerBar(int beats) => _setBeatsPerBar(beats);
static void setUseAccentTick(bool value) => _setUseAccentTick(value);
static void setTickCallback(Pointer<NativeFunction<Void Function(Int32)>> callback) {
  _setTickCallback(callback);
}
```

## 5. 平台支持范围

来自 `lib/ffi.dart:5-8` 与 `ios/`、`android/` 目录:

- **Android**:完整支持(Native C++/Oboe)
- **iOS**:仅 UI scaffold(目录存在,但 FFI 加载抛 `UnsupportedError`)
- **Web/Desktop**:不支持

也就是说当前仓库是 **Android-first** 方案,iOS 仅有占位符。
