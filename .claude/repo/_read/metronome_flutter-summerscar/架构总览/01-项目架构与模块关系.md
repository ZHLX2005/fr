### 7.2 核心调度循环 — `runTimer`

`main.dart:83-88`:

```dart
void runTimer() {
  timer = Timer(Duration(milliseconds: (60 / _bpm * 1000).toInt()), () {
    _playAudio().then((value) => _setNowStep());
    runTimer();
  });
}
```

**算法**:
- 间隔 = `60 / BPM * 1000` ms,例如 BPM=60 → 1000ms/拍
- 单次 `Timer` 而不是 `Timer.periodic` 的原因:每次重新创建时使用最新 `_bpm`,避免周期性 Timer 引用旧值
- 回调内先播放音频再 `_setNowStep()`,触发 UI 重建
- 然后递归调 `runTimer()` 形成循环

### 7.3 音频播放 — 按重音/普通分类

`main.dart:74-81`:

```dart
Future<void> _playAudio() {
  int nextStep = _nowStep + 1;
  if (nextStep % 4 == 0) {
    return assetsAudioPlayer.open(Audio('assets/metronome$soundType-1.mp3'));
  } else {
    return assetsAudioPlayer.open(Audio('assets/metronome$soundType-2.mp3'));
  }
}
```

- `_nowStep + 1` → 计算下一拍
- `nextStep % 4 == 0` → 重音(`-1.mp3`)
- 否则普通 (`-2.mp3`)
- **注意**:这是**写死 4 拍一小节**的简化版,而非 MateusNavarro77 的 `beatsPerBar` 可配置

`assets_audio_player.open(Audio(...))` 每次都重新打开音频文件(非缓存),所以听感上是"短促音效"循环。

### 7.4 启动/暂停切换

`main.dart:55-66`:

```dart
void _toggleIsRunning() {
  if (_isRunning) {
    timer.cancel();
    _animationController.reverse();
  } else {
    runTimer();
    _animationController.forward();
  }
  setState(() {
    _isRunning = !_isRunning;
  });
}
```

- 暂停:`timer.cancel()` + 反向动画(播放图标变暂停图标)
- 启动:`runTimer()` + 正向动画

## 8. UI 组件

### 8.1 IndactorRow (节拍圆点) (`indactor.dart:1-27`)

```dart
class IndactorRow extends StatelessWidget {
  final int nowStep;
  final List steps = List.filled(4, null);
  IndactorRow(this.nowStep);

  @override
  Widget build(BuildContext context) {
    return Row(
        mainAxisAlignment: MainAxisAlignment.center,
        children: steps
            .asMap()
            .entries
            .map((entry) => Container(
                margin: EdgeInsets.all(25),
                width: entry.key == 0 ? 35.0 : 25.0,
                height: entry.key == 0 ? 35.0 : 25.0,
                decoration: BoxDecoration(
                    borderRadius: BorderRadius.circular(100),
                    color: this.nowStep > -1 &&
                            (this.nowStep % steps.length) == entry.key
                        ? Color.fromARGB(255, 102, 204, 255)
                        : Colors.grey[300])))
            .toList());
  }
}
```

- 写死 4 个圆点 (`List.filled(4, null)`)
- 第 0 个圆点更大 (`35.0`) 表示重音位
- 激活颜色 `102, 204, 255` 浅蓝;未激活灰色

## 9. 关键设计要点

| 设计点 | 实现 |
|--------|------|
| 调度源 | Dart 单次 `Timer` + 递归 (主线程) |
| 音频方案 | `assets_audio_player` 预录 mp3 资源 |
| 状态管理 | Flutter `setState` (无 Bloc/Riverpod) |
| 视觉反馈 | `_animationController` + `AnimatedIcon` play/pause |
| 持久化 | `SharedPreferences` (BPM + 音效选择) |
