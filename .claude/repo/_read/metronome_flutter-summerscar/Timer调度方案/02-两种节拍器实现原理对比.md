## 2. 节拍调度核心对比

### 2.1 调度源不同

**MateusNavarro77 — 音频回调 + sample 计数**

`android/app/src/main/cpp/metronome.cpp:33-35`:

```cpp
void updateTiming() {
    samplesPerBeat = sampleRate * 60.0 / bpm;
}
```

每次 BPM 改变都重算 `samplesPerBeat`,然后在音频回调的 `for (int i = 0; i < numFrames; i++)` 循环里,以 `sampleCounter++` 单步累加,触发拍点。**音频硬件时钟是真相**,Dart 调度不参与。

**summerscar — Dart Timer 递归**

`lib/main.dart:83-88`:

```dart
void runTimer() {
  timer = Timer(Duration(milliseconds: (60 / _bpm * 1000).toInt()), () {
    _playAudio().then((value) => _setNowStep());
    runTimer();
  });
}
```

**Dart 单 isolate 主线程 Timer 是真相**,受 GC + 帧调度影响,精度 < MateusNavarro77。

### 2.2 BPM 改变时的响应差异

MateusNavarro77:Native C++ 直接改 `bpm` 字段,下一次拍点立刻生效(`onAudioReady` 中 `sampleCounter >= samplesPerBeat` 是基于最新值)。

summerscar:**正在等待中的旧 timer 周期不会缩短**,必须等当前拍走完,下一次 `runTimer()` 才会用最新 `_bpm`。

## 3. 音频合成对比

### 3.1 MateusNavarro77 — 程序化正弦合成

`metronome.cpp:86-100`:

```cpp
float sample = 0.0f;
if (clickRemaining > 0) {
    double t = (double) clickRemaining / sampleRate;
    sample = (float)(
            0.8 *
            sin(2.0 * M_PI * frequency * t) *
            (clickRemaining / 200.0)
    );
    clickRemaining--;
}
```

- 重音 1500Hz / 普通 1000Hz
- 包络:`clickRemaining / 200.0` 线性衰减 200 sample (≈ 4.2ms @48kHz)
- 0 字节音频资源,音色可调

### 3.2 summerscar — 预录制 mp3

`lib/main.dart:74-81`:

```dart
Future<void> _playAudio() {
  int nextStep = _nowStep + 1;
  if (nextStep % 4 == 0) {
    return assetsAudioPlayer.open(Audio('assets/metronome$soundType-1.mp3'));
  } else {
    return assetsAudioPlayer.open(Audio('assets/metronome$soundType-2.mp3'));
  }
}
```

- 4-5 个 mp3 资源(`metronome0-1.mp3`、`metronome0-2.mp3`、`metronome1-1.mp3`、`metronome1-2.mp3`、`di.mp3`)
- 写死 4 拍一小节
- 每次 `open` 触发 `assets_audio_player` 异步 IO 加载并播放

## 4. 状态管理对比

### 4.1 MateusNavarro77 — Bloc + sealed events

`lib/blocs/metronome/metronome_bloc.dart:36-61` 提供 9 个事件 (Paused/Played/BpmChanged/Ticked/BpmIncremented/BpmDecremented/AccentFirstBeatToggled/BeatsPerBarChanged/Tapped),完全可测试 (`bloc_test` + `mocktail` 在 `pubspec.yaml:60-62` 已配置)。

### 4.2 summerscar — `setState`

`lib/main.dart:39-163` 所有状态以私有字段 (`_bpm` / `_nowStep` / `_isRunning` / `soundType`) 维护,直接在 `_MyHomePageState` 内操作。简洁但难以测试。

## 5. 跨端能力对比

| 维度 | MateusNavarro77 | summerscar |
|------|---------------|------------|
| Android | ✓ (Native C++/Oboe) | ✓ |
| iOS | ⚠ 仅 UI scaffold,FFI 抛 `UnsupportedError` (`lib/ffi.dart:7-8`) | ✓ |
| Web | ✗ (FFI 不支持) | ✓ (有在线 demo `summerscar.me/metronome_flutter/`) |
| Windows/macOS/Linux | 未涉及 | 包支持 (`assets_audio_player` 多端) |
| Wakelock | `WakelockPlus` `home_page.dart:38-41` | `Wakelock` (移动端 `!kIsWeb`) |
| 持久化 | `hydrated_bloc` (主题) | `SharedPreferences` (BPM + 音效) |

## 6. 性能与精度对比

| 场景 | MateusNavarro77 | summerscar |
|------|---------------|------------|
| 单拍调度抖动 | < 1 sample (≈ 20μs @48kHz) | 10-50 ms (Timer + GC) |
| BPM 改变响应 | 立即生效 (下一拍) | 需等当前拍结束 |
| CPU 占用 | 中等 (音频回调持续) | 极低 (Timer 唤醒) |
| 内存 | 共享库加载 (~MB 量级) | mp3 解码缓存 |
| 启动延迟 | `init_audio` 创建 Oboe 流 | `SharedPreferences` IO |

## 7. 实现复杂度对比

| 维度 | MateusNavarro77 | summerscar |
|------|---------------|------------|
| 代码行数 (核心) | C++ `metronome.cpp` 199 行 + Dart Bloc/UI 数百行 | 单文件 `main.dart` 163 行 + 4 个小组件 |
| 构建工具 | Android NDK + CMake (`CMakeLists.txt`) | Flutter 默认工具链 |
| 测试 | `bloc_test` + `mocktail` + `test/` 目录 | 无 |
| 设计模式 | Clean Architecture (domain/data/blocs/view) | 单 StatefulWidget |
| Tap Tempo | 完整 5 次滑动窗口 + 2s 超时 (`metronome_bloc.dart:36-61`) | 无 |

## 8. 适用场景推荐

| 场景 | 推荐 | 原因 |
|------|------|------|
| 音乐练习 (专业级精度) | MateusNavarro77 | 音频回调调度,亚毫秒精度 |
| 跨端 Web demo | summerscar | 有在线 demo,Web 一致性 |
| 原型 / 快速开发 | summerscar | 30 行核心,极简 |
| 教学场景 | 两者兼有 | 不同复杂度都是好教材 |
| 录音棚节拍器 | MateusNavarro77 | 精度决定一切 |
| 自定义音色 | MateusNavarro77 | 程序化合成参数可调 |
| iOS-only 发布 | summerscar | FFI iOS 端未实现 |

## 9. 可复用模式抽取

如果自己要实现 Flutter 节拍器,可以借鉴的关键模式:

### 9.1 来自 MateusNavarro77

- **Clean Architecture 分层**:`domain/` 接口 → `data/` 实现 → `blocs/` 状态 → `view/` UI
- **FFI + Oboe 实时合成**:追求精度时的不二选择
- **`NativeCallable.listener`** 安全跨 isolate 回调 (`metronome_impl.dart:28-30`)
- **滑动窗口 Tap Tempo 算法** (5 次敲击 + 2s 超时)
- **`WidgetsBindingObserver` + `buildWhen`** 精确控制 lifecycle 与重建

### 9.2 来自 summerscar

- **单次 Timer 递归**而非 `periodic` — BPM 可变场景适用
- **极简 `setState` 模式** — 内部 demo / 教学示例
- **`kIsWeb` 平台判断** — 跨端场景下跳过平台特定 API
- **`SharedPreferences`** 配置持久化的最简方案
- **预录制音频 + 短触发** — `assets_audio_player.open` 单次播放短音效
