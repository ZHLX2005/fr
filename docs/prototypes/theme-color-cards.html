筛选

提案落地规则（改 token 时）

  1. surface / surfaceContainerHighest：ΔL 约 3–6，彩度接近；托盘不得比 primaryContainer 更艳。
  2. secondary / onSurfaceVariant：从 surface 家族取灰，禁止另起一条冷暖相反的灰轴（Lemon 禁蓝灰、Purple 禁棕灰）。
  3. tertiary：每屏稀用；与 primary 色相距 ≥ 60°；不要同时当大按钮底和大面积 container。
  4. primary：中低彩签名色；Filled 大按钮可接受，但 onPrimary 必须按对比度选（勿假定纯白）。
  5. lib/ 仍禁裸 hex：本页 hex 只服务提案；确认后写回 *Colors.scheme。
