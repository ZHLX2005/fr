远控设置页 · 就地管理定稿

布局区是一张大卡片：上栏竖屏组、下栏横屏组，两组列表各自独立拖拽排序。点行 = 切该组激活；管理只从行尾 ⋯ 进入（无长按）。可用性由分组表达——不可用的布局不进该组，行状态只剩两态。

基线 提案 C 就地管理 模型 activeId / activeIdPortrait 分组即朝向 · 组内顺序沿用面板既有语义 日期 2026-10-23
01

交互原型

可操作：点行切换该组激活 · 点 ⋯ 开行菜单 · 拖把手组内排序 · 尾行新建。「模拟入口」切换验证应用设置入口下「在画布上编辑」自动隐藏。

  • 1竖屏组头——组名 + 数量 + 右侧「当前」回显；横屏组同构。
  • 2行把手——按住拖动 = 组内排序，两组互不影响；顺序即时落盘。
  • 3行尾 ⋯——唯一管理入口（无长按）。菜单朝向随组而定，不再需要按朝向分组。
  • 4横屏组——写字不出现（无横屏形态）、方向键/轮盘/键盘不进竖屏组（横屏专用模块），可用性由分组表达。
  • 5新建落点——大卡下方虚线行；双朝向自定义布局创建后两组各出现一行。
双朝向布局（触控屏 / 自定义）在两组各有一行——数据本就按朝向各存一份锚点，菜单里编辑哪行就改哪组。组内排序沿用现面板「横竖屏两组各自拖拽」的既有语义，只是从抽屉搬进设置页。
