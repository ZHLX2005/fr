画布布局

当前：方向键布局

拖动调整 横屏 切换顺序；与竖屏互不影响。

顺序 = 布局切换器展示顺序 · 仅当前设备朝向可点选激活

交互契约

  • 编排与激活拆开：顶部「横屏/竖屏编排」只管顺序；点选激活仍受设备朝向约束（另一朝向行半透明）。
  • 拖拽：按住左侧 ≡，组内重排；落点指示线；松手写入该朝向顺序。
  • ⋯ 与长按：同一套小圆角卡片，贴行锚定，不占底栏 sheet。
  • 修改：关面板 → 画布进编辑态；工具栏按朝向收纳（见下）。
  • 恢复：仅内置；自定义无此项，改为重命名 / 删除。

编辑工具栏收纳

  • 竖屏：头部居中「编辑工具」收纳钮 → 点开顶部功能显隐列表。
  • 横屏：收纳放到右侧（竖排标签），不占头部，避免挡左上胶囊与手柄区。
  • 列表：模块显隐 chip（开=实心 / 关=虚线幽灵）+ 布局 / 快捷键 / 完成。
  • 进入编辑默认收纳，需要时再展开，少挡画布。

游戏布局拆分

  • 方向键布局：十字键四向（离散按键），右手 ABXY/肩键。
  • 轮盘布局：左轮盘（拖动吸附 / 回中），右手同面键。
  • 缩略图用十字 vs 圆盘区分，避免「游戏」一词混两种手感。
  • 待拍板：竖屏要不要内置游戏变体，还是仅横屏锁定？
与现网差异 / 落代码要点

相对 rt_canvas_layouts_sheet

现网：长按 → 底栏 sheet 或确认框；自定义行右侧 more 图标不可点；无拖拽排序；单一「游戏布局」含轮盘。
原型：⋯ 可点；长按同菜单；组内拖拽；游戏拆两条内置；编排 tab 可先改另一朝向顺序。

建议持久化

orderLandscape[] / orderPortrait[]（id 序列），与 activeId / activeIdPortrait 独立。
内置 id 建议：game_dpad、game_wheel（替换原单一 game）。

相对 rt_canvas_view._editChrome

现网：横竖屏都是顶部居中 chip 行（可收起为「编辑工具」仍在顶）。
原型：竖屏收纳/展开都在头部；横屏收纳与展开列表都在右侧竖轨，头部留给胶囊，不挡手柄。
