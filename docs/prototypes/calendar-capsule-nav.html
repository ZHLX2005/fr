这是什么

fr 日历模块重构的交互原型（任务 #36）。顶部导航换成胶囊导航（年 / 月 / 周 / 日 / 日程）；月视图双态——收起 = 单周行 + 任务面板，展开 = 整月网格；原「列表」视图拆入月·收起态与日程。

布局参照 MIUI 日历原型图（仅布局），配色为茶禅主题：抹茶 × 焙茶金 × 柿朱（柿朱仅用于「今天」）。农历 / 节气 / 节日为真实换算（solarlunar 内联）。

交互速查

胶囊点按页签弹簧切换，指示条微回弹
月历 / 面板拖拽上拖收起月历 / 下拖展开（跟手 + 阻力 + 松手吸附）
月历横向滑动翻月（速度感知 + 动量投射）
抓手 / 面板头部点按收起 / 展开切换
周条横向滑动翻周（周 / 日页共用）
时间轴 / 列表拖拽滚动，两端 iOS 阻力 + 惯性回弹
右下 ＋新建日程（抓手下拉可关）
右下 今回到今天并展开月历
年页点月份跳转该月（弹簧转场）

动效参数（移植自通知栏 demo）

跟手吸附弹簧　k=205　c=29（SpringSimulation 同参）
胶囊 / 页签弹簧　k=300　c=24（微回弹）
收起端阻力　62·(1−e^(−x/130))
列表端阻力　(1−1/(0.55x/d+1))·d（WebKit 式）
动量投射　松手前 130ms → 最近档位
指针死区　4px；渐入 smootherstep（C² 连续）
减少动态效果 → 全部动画瞬时到位
