布局形态

  • 横竖双朝向：顶部「⤢ 横屏 / ⤡ 竖屏」切换；游戏 / 键盘布局锁定横屏，竖屏时浮出毛玻璃提示层引导旋转（可一键切回或就地切换布局），触控屏布局双朝向可用
  • 布局面板方向感知：横屏自左侧抽屉滑入（通高、grab 柄竖贴右缘），竖屏自底部上滑
  • 游戏 = 纯手柄：左拖动轮盘（vpad_dpad 四向吸附，松手回中）+ 右手柄键区 ABXY + LB/LT/RT/RB
  • 键盘 = 全键盘（Fn 行折叠，无输入条） · 触控屏 = 全屏触摸板
  • 操作区收在左上胶囊，收起时只显示「布局名 + 状态点」
  • 模块避让：顶部 56px / 侧边 8px（全屏触摸板豁免）
