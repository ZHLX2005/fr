对齐 AppThemeMode 五套主题： 茶禅 / 暮紫 / 墨白 / 粉雾海盐 / 柠檬鼠尾草。 色值取自 lib/core/theme/tokens/color/theme/*.dart， 切主题看游戏中心、房间就绪、大厅入口在各主题下的观感。

茶禅 Zensage 主色 ↔ 暖米环境。现网默认主题；主 CTA 走 primary，tertiary/clay 只做收藏与警告。

五主题速查

Zen 默认。sage CTA + 暖米底；tertiary clay 只做收藏/错误。
Purple 唯一 dark。暮紫 CTA + 鎏金 tertiary；房间深底最贴。
Ink 近黑 CTA + 纸白底；墨赭 tertiary 作章印强调。
Rose 粉 CTA（深字）+ 海盐薄荷 tertiary；表面偏粉雾。
Lemon 亮黄 CTA（深字）+ 鼠尾草绿 tertiary；最跳、最「闲鱼」。
落地约束 游戏表面必须吃 ColorScheme，不要写死 sage/clay；Lemon/Rose/Purple 的 onPrimary 不是白，按钮文字跟 token。
