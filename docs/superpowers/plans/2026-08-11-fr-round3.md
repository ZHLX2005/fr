# Part B — calendar 进入闪屏（#2）

**根因（已读码确认）：** `LabCalendarProvider`/`LabPeopleProvider` 在 `calendar_demo.dart` 的 `buildPage` 内 `create`（未预热），构造里 `await CalendarRepository.instance.init()`（Hive 开箱 50-200ms）→ 首帧 `_events`/`_people` 为空列表 → 5 个视图直接渲染空数据 → 0.1-0.2s 后数据到位重画 = 闪屏 + 组件闪烁。

**修法（用户拍板：B · 视图加 loading 占位）：** provider 加 `ready` 标志；`_CalendarDemoPageState.build` 在任一 provider 未 ready 时 body 渲染居中 loading（覆盖全部 5 视图），ready 后渲染 PageView。
