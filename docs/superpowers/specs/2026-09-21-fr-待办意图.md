## 簇 A · 对局回放一级化 + 快照统一残局（id 61）

### 任务原文
> 对局回放应该是和皮肤平行，然后可以欣赏，然后对局回放当中支持选择一个节点创建残局，现在开房间的时候不需要对局回访呀，只需要选择残局，这个依赖关系是错误的当前

### 对齐后的意图
1. **「对局回放」升级为一级主页面**：查看所有已保存的对局回放（现有 `ChessGameRecordListPage` 的能力升级入口层级）。
2. **回放皮肤跟随当前选中皮肤**（prefs key `chess_skin_id`）。提交方明确：**不需要**在记录里存"对局当时皮肤"。
3. **回放中可把某一手局面保存为快照**；**快照 = 原「残局」概念，二者统一**，不再维护两套入口/概念。
4. **开房间只从快照列表选**：房间准备面板里不再出现「对局回放库」入口，只保留「选择快照（原残局）」。

### 现状与差距（代码事实）
- 回放库入口目前挂在房间准备卡（`chess_room_page.dart:1691-1695`），皮肤链 `widget.localSkin ?? ChessSkinBundle.byId(widget.skinId)`（`:871-878`），回放页兜底 `byId('1')`（`chess_game_replay_page.dart:49-50`）→ **与"当前选中皮肤"不同源**。
- 「当前选中皮肤」唯一写入点 `chess_online_demo.dart:280`，读取 `:117-121`；**无可订阅的全局入口**。
- "回放中选节点创建残局"能力**已在房间页回放条实现**：`chess_room_page.dart:1293 _exportCurrentReplayPosition` → `ChessEndgameSnapshot{label, fen, lineageMoves, lineageMoveIndex}`（`:1298-1319`，`source: replay`），但回放库页未接线（`chess_game_replay_page.dart:212-223` 未传 `onExport`/`onSaveGame`）。
- 残局选择入口在规则面板（`chess_room_config_page.dart:231-238`），与回放库按钮并列无依赖。

### 边界
- 不改回放数据格式（`fr-chess-game` v1 保持）；不新增"当时皮肤"字段。
- 残局库已有的导入/AI 提示词能力保留，只是概念上并入"快照"。

### 验收
- 从一级入口（非房间内）可进入回放库并完整回放；回放页棋子样式与设置页当前选中皮肤一致。
- 回放页内可对任意一手保存快照，快照出现在开房间的"选择快照"列表里。
- 房间准备面板不再有回放库入口；残局/快照选择照常可用。

- `bootstrapLab` 的懒注册属于大改，是否纳入本簇**待提交方拍板**（本簇最低目标 = 删硬编码皮肤 + 强拉）。

### 验收

## 簇 C · 退出不终止对局（id 47）

### 任务原文
> 退出按钮不要回调房间终止 action，提示对方暂时离线即可
> （范围澄清）所有联机房间页
> （收尾决策）双方都离线超时后服务端自动终止

### 病根（已定位）
`chess_script_lifecycle.dart:265-282` `on_leave`：playing/ready 态下，非 `disconnect` 的 leave 且是 host → `state="ended"` + `end_reason="host_left"` + `force_leave` guest（踢人）。客户端退出按钮 `_leaveAndPop`（`chess_room_page.dart:1500`）→ `POST /leave`（reason 非 disconnect）即触发。

### 对齐后的意图
1. 所有游戏 Lua 脚本的 `on_leave`：**主动退出（点退出按钮）与断线同等对待**——标记 `disconnected`，不终止、不踢人。
2. 对方侧提示"暂时离线"（复用现有 disconnected UI：`chess_connection_status.dart:84`、`relay_connection_bar.dart:95`）。
3. 房间收尾：双方均离线超过阈值（时长待定，建议 10 分钟）→ 服务端自动终止。

### 边界
- 改动落在**各游戏 Lua 脚本**（chess/sudoku/tetris/…同款逻辑都要改）+ 服务端超时机制；客户端退出按钮行为基本不变。
- 断线重连回房（`c.disconnected` 恢复路径）现有逻辑需回归验证。

### 验收
- host 在 playing 中点退出 → 房间不 ended、guest 收到"暂时离线"提示且不被踢；guest 侧同。
- 双方都离开超阈值后房间自动终止（无僵尸房间）。
