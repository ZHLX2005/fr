## 当前链路（探索后）

- **Dart 数据**：`lib/native/home_widget/clock_widget_data.dart` `ClockWidgetData.fromClock` 已携带 `isRunning/remainingSeconds/durationSeconds/color/startTimeMs/startRemainingSeconds` 9 字段；无 `isPausedAtStart`，native 只能二态（running/!running），所以「等待开始」与「已暂停」都进 `else` 显示「已暂停」。
- **Dart 同步**：`LabClockProvider._syncToWidget()` 在 11 个状态变化点调用 `ClockWidgetService.updateClockWidget`，数据写入 SharedPreferences（home_widget 插件），最终 broadcast `HomeWidget.updateWidget(qualifiedAndroidName: ...)` → 30 分钟内或下次 Flutter tick 触发 native `ClockWidgetProvider.onUpdate`。
- **Native UI**：`android/app/src/main/res/layout/clock_widget.xml` 现有 FrameLayout（容器可点 + 右上角图标 refresh PendingIntent），无任何 Button/ImageButton。`ClockWidgetProvider.kt` 第 76-80 行三态分支（overtime/running/paused），paused 是兜底。`widget_info.xml` minWidth=180dp / minHeight=110dp / updatePeriod=1800000。
- **Native 按钮集成**：`RemoteViews` 支持 ImageButton/Button/TextView 可点击；`setOnClickPendingIntent(viewId, pendingIntent)`；按钮与现有容器/refresh 图标用不同 view id + 不同 requestCode（建议按钮用 `appWidgetId + 1000`）。
- **路由**：现有 `fr://lab/demo/{key}` 等；本任务新增 `fr://clock/widget-toggle`（authority 不与 `lab` 冲突）。
- **「最新的 clock」**：`_clocks.insert(0, clock)` 维护，`_clocks.first` 是最新；toggle 三态见下。

## 改动清单

### Dart

1. `lib/native/home_widget/clock_widget_data.dart`
   - 新增 `final bool isPausedAtStart` 字段（构造参数 + `toMap` 序列化 key `clock_is_paused_at_start`）。
   - `fromClock` 工厂方法自动推导：`isPausedAtStart = !isRunning && remainingSeconds == durationSeconds`。
   - `ClockWidgetData.empty` 默认 `false`。
2. `lib/lab/demos/clock/providers/lab_clock_provider.dart`
   - 新增公共方法 `toggleLatestClock()`：无 clock→无操作；运行中→`pauseCountdown`；否则（等待开始/已暂停）→`startCountdown`。
3. `lib/native/home_widget/clock_widget_service.dart`
   - `updateClockWidget` 的 `Future.wait` 增加 `saveWidgetData(_keyIsPausedAtStart, data.isPausedAtStart ? '1' : '0')`。
4. `lib/core/schema/handlers/clock_widget_toggle_handler.dart`（新建）
   - 仿 RecorderHandler：返回打开 ClockDemo 的包装页 + `markClockWidgetToggle()` 标记，让 ClockDemo 进入后立刻 `toggleLatestClock()`。
5. `lib/core/schema/bootstrap_routes.dart`
   - `registerAll` 列表新增 `FrRoute('clock/widget-toggle', handler: const ClockWidgetToggleHandler())`。

### Native（Android）

1. `android/app/src/main/res/layout/clock_widget.xml`
   - 在 `widget_container` 内新增 `ImageButton` `@+id/widget_toggle_btn`（48dp，bottom|center_horizontal，marginBottom=12dp，背景透明）。
2. `android/app/src/main/kotlin/io/github/xiaodouzi/fr/native/widget/ClockWidgetProvider.kt`
   - 第 76-80 行三态分支重构为四态：新增 `isPausedAtStart` 读取 prefs → 独立分支显示「等待开始」文案 + 略浅灰色（0xFF9E9E9E）。
   - `updateAppWidget` 末尾新增 toggle 按钮：
     - `setOnClickPendingIntent(R.id.widget_toggle_btn, ...)`，Intent `ACTION_VIEW` + `fr://clock/widget-toggle`，requestCode=`appWidgetId + 1000`，FLAG_IMMUTABLE|FLAG_UPDATE_CURRENT。
     - `setImageViewResource(R.id.widget_toggle_btn, ...)` 按 `isRunning` 切换播放/暂停图标。
     - `setColorInt(R.id.widget_toggle_btn, "setColorFilter", style.color, style.color)` 让按钮 tint 跟状态色。
